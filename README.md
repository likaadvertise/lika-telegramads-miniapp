# Lika Ads — Telegram Mini App

مینی‌اپ تلگرامی **Lika Network** برای ثبت سفارش تبلیغات Telegram Ads.
مشتری داخل تلگرام اطلاعات کمپین خود را وارد می‌کند و تیم Lika آن را بررسی و اجرا می‌کند.

---

## وضعیت فعلی پروژه

**فاز ۱ — رابط کاربری ✅**
رابط کاربری کامل، فارسی، راست‌به‌چپ و موبایل‌محور.

**فاز ۲ — ربات، سرور و دیتابیس ✅ (کد آماده است)**
ربات تلگرام، سرور و دیتابیس نوشته و تست شده‌اند. برای روشن شدن فقط به توکن ربات
و یک آدرس اینترنتی نیاز است (بخش «راه‌اندازی سرور» را ببینید).

**باقی‌مانده:** اتصال فرم مینی‌اپ به API سرور. تا آن زمان مینی‌اپ سفارش‌ها را
روی گوشی مشتری ذخیره می‌کند، نه روی سرور.

## چه چیزهایی ساخته شده

| صفحه | کاربرد |
|---|---|
| خانه | خوش‌آمدگویی، آمار کمپین‌ها، دکمهٔ ثبت کمپین، معرفی خدمات |
| ثبت کمپین | فرم ۵ مرحله‌ای با پیش‌نمایش زندهٔ تبلیغ |
| کمپین‌های من | لیست کمپین‌ها با فیلتر وضعیت |
| جزئیات کمپین | تایم‌لاین وضعیت، آمار عملکرد، مشخصات کامل |
| مشاوره | ارتباط با کارشناس + سوالات متداول |
| حساب من | پروفایل تلگرامی، آمار کلی، تنظیمات |
| قوانین | خلاصهٔ قوانین تبلیغات تلگرام |

**پنج مرحلهٔ فرم ثبت کمپین:**

1. **مقصد تبلیغ** — کانال/گروه، ربات یا پست + آدرس + نام برند
2. **متن تبلیغ** — با شمارندهٔ ۱۶۰ کاراکتر و پیش‌نمایش زنده (یا سفارش نگارش به تیم Lika)
3. **مخاطب هدف** — کشور، زبان، موضوع کانال‌ها، کانال‌های خاص
4. **بودجه و نرخ** — بودجه (حداقل ۱۰ دلار)، نرخ CPM، بازدید تخمینی، زمان شروع
5. **بازبینی نهایی** — خلاصهٔ سفارش + پذیرش قوانین

**ویژگی‌های فنی:**

- هماهنگ با تم روشن/تیرهٔ تلگرام
- دکمهٔ Back و لرزش (Haptic) تلگرام
- نمایش نام و عکس کاربر از پروفایل تلگرام
- اعداد فارسی، تاریخ شمسی، معادل تقریبی تومان
- ذخیرهٔ خودکار پیش‌نویس (اگر مشتری نیمه‌کاره خارج شود)
- اعتبارسنجی فارسی در هر مرحله

## ساختار فایل‌ها

```
web/                            ← مینی‌اپ (چیزی که مشتری می‌بیند)
├── index.html
└── assets/
    ├── css/app.css             ← ظاهر و رنگ‌ها
    ├── fonts/                  ← فونت وزیرمتن
    └── js/
        ├── config.js           ← ⭐ تنظیمات (اعداد و متن‌ها را اینجا عوض کنید)
        ├── icons.js            ← آیکون‌ها
        ├── store.js            ← ذخیره‌سازی داده‌ها
        └── app.js              ← منطق صفحه‌ها و فرم

server/                         ← ربات و سرور (چیزی که تیم Lika می‌بیند)
├── .env.example                ← ⭐ نمونهٔ تنظیمات؛ کپی کنید به .env
└── src/
    ├── index.js                ← شروع سرور
    ├── config.js               ← خواندن تنظیمات
    ├── db.js                   ← دیتابیس SQLite
    ├── auth.js                 ← بررسی امضای تلگرام
    ├── validate.js             ← بررسی اطلاعات سفارش
    ├── api.js                  ← آدرس‌های API مینی‌اپ
    ├── bot.js                  ← منطق ربات
    ├── telegram.js             ← ارتباط با API تلگرام
    ├── format.js               ← متن پیام‌های فارسی
    └── labels.js               ← برچسب‌های فارسی
```

### فایلی که خودتان می‌توانید تغییر دهید

`web/assets/js/config.js` — بدون دانش برنامه‌نویسی می‌توانید این‌ها را عوض کنید:

- `supportUsername` و `channelUsername` — آیدی پشتیبانی و کانال
- `minBudget` — حداقل بودجه (الان ۱۰ دلار)
- `minCpm` / `maxCpm` / `defaultCpm` — بازهٔ نرخ CPM
- `usdToToman` — نرخ دلار برای نمایش تقریبی به مشتری *(هر چند وقت به‌روز کنید)*
- `countries` / `languages` / `topics` — گزینه‌های هدف‌گیری
- `adRules` / `faq` / `services` — متن‌های قوانین، سوالات متداول و خدمات
- `seedSampleData` — با `false` کردن آن، کمپین‌های نمونه ساخته نمی‌شوند

## اجرای پروژه روی کامپیوتر خودتان

نیازی به نصب چیز خاصی نیست؛ فقط یک سرور محلی لازم است:

```bash
cd web
npx http-server -p 8080
```

سپس در مرورگر باز کنید: `http://localhost:8080`

## راه‌اندازی سرور و ربات

### پیش‌نیاز
Node.js نسخهٔ ۲۲٫۵ یا بالاتر (دیتابیس داخلی خود Node استفاده می‌شود، پس چیز دیگری نصب نمی‌کنید).

### ۱) ساخت ربات
در تلگرام به [@BotFather](https://t.me/BotFather) پیام بدهید:

| کاری که می‌کنید | نتیجه |
|---|---|
| `/newbot` | ربات جدید می‌سازد |
| نام ربات را بنویسید (مثلاً `Lika Ads`) | نام نمایشی |
| آیدی ربات را بنویسید (باید به `bot` ختم شود، مثلاً `LikaAdsBot`) | آدرس ربات |
| توکن را کپی کنید | چیزی شبیه `1234567890:AAF...` |

### ۲) تنظیمات
```bash
cd server
cp .env.example .env
```
سپس `.env` را باز کنید و پر کنید:
- `BOT_TOKEN` — توکنی که از BotFather گرفتید
- `WEBAPP_URL` — آدرس اینترنتی مینی‌اپ (باید `https` باشد)
- `ADMIN_CHAT_ID` و `ADMIN_IDS` — با دستور `/id` در ربات پیدا می‌شوند

### ۳) اجرا
```bash
npm start
```

### دستورهای ربات
| دستور | کار |
|---|---|
| `/start` | خوش‌آمد + دکمهٔ باز کردن پنل |
| `/orders` | سفارش‌های کاربر |
| `/id` | نمایش شناسهٔ عددی چت (برای پر کردن `.env`) |
| `/help` | راهنما |

### گردش کار سفارش
1. مشتری در مینی‌اپ سفارش ثبت می‌کند
2. سفارش در دیتابیس ذخیره می‌شود
3. پیام کامل سفارش به چت تیم Lika می‌رود، همراه دکمه‌های تغییر وضعیت
4. تیم روی یکی از دکمه‌ها می‌زند (در حال بررسی / تأیید / شروع اجرا / نیاز به اصلاح / پایان)
5. مشتری بلافاصله از تغییر وضعیت باخبر می‌شود

### امنیت
- هر درخواست با امضای رسمی تلگرام (`initData`) بررسی می‌شود؛ کسی نمی‌تواند خودش را جای مشتری دیگری جا بزند
- همهٔ اطلاعات سفارش در سرور دوباره اعتبارسنجی می‌شود (به فرم اعتماد نمی‌شود)
- سقف تعداد درخواست و تعداد سفارش روزانه برای هر کاربر
- فایل `.env` در `.gitignore` است و هرگز در گیت‌هاب قرار نمی‌گیرد

## مراحل بعدی

| فاز | کار | نتیجه |
|---|---|---|
| ۲٫۵ | اتصال فرم مینی‌اپ به API سرور | سفارش‌ها واقعاً به تیم Lika می‌رسد |
| ۳ | پنل ادمین تحت وب | مدیریت کامل سفارش‌ها، ثبت آمار، جستجو و گزارش |
| ۴ | درگاه پرداخت | تسویهٔ آنلاین درون مینی‌اپ |
| ۵ | اتصال به Telegram Ads | کاهش کار دستی و اجرای خودکار کمپین |

### دربارهٔ فاز ۵ (اتوماسیون)

پلتفرم رسمی Telegram Ads در حال حاضر API عمومی و مستندی برای ساخت خودکار کمپین ندارد؛
اتوماسیون کامل به دسترسی سطح پارتنر/ریسلر نیاز دارد که موضوعی قراردادی است، نه فنی.
به همین دلیل ساختار دادهٔ این پروژه از ابتدا **دقیقاً مطابق فیلدهای Telegram Ads** طراحی شده
تا هر زمان آن دسترسی فراهم شد، فقط یک لایهٔ اتصال اضافه شود و بقیهٔ پروژه دست‌نخورده بماند.
تا آن زمان می‌توان مسیر را نیمه‌اتوماتیک کرد (تولید خودکار خروجی آمادهٔ کپی برای اپراتور).
