# تصویرهای پروژه

لوگوی شرکت را اینجا بگذارید — مثلاً `logo.png`.

سپس در فایل `web/assets/js/config.js` این خط را پر کنید:

```js
brandLogo: "./assets/img/logo.png",
```

**مشخصات پیشنهادی لوگو:**

- قالب: `PNG` با پس‌زمینهٔ شفاف (یا `SVG`)
- اندازه: مربع، حداقل ۲۵۶×۲۵۶ پیکسل
- حجم: کمتر از ۱۰۰ کیلوبایت

لوگو داخل یک مربع با گوشهٔ گرد نمایش داده می‌شود، پس اگر لوگوی شما
مستطیلی و کشیده باشد، بهتر است نسخهٔ مربعی (فقط نشان، بدون نوشته) بسازید.
