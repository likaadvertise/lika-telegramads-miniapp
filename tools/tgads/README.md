# پر کردن خودکار فرم Telegram Ads

این ابزار روی **کامپیوتر خودتان** اجرا می‌شود، پنل `ads.telegram.org` را باز
می‌کند و فرم «Create Your Ad» را از روی یک سفارش پر می‌کند — و همان‌جا می‌ایستد.

دو راه برای استفاده هست:

| راه | برای کِی |
|---|---|
| **دستیار + دکمهٔ CRM** (پیشنهادی) | همیشه — با یک کلیک در پنل CRM، بدون کپی/پیست |
| **خط فرمان** | اگر دستیار در دسترس نبود، یا می‌خواهید تک‌تک تست کنید |

## چه چیزی را پر می‌کند و چه چیزی را نه

| فیلد | وضعیت |
|---|---|
| Target (Channels / Bots / Search) | ✅ از روی نوع سفارش |
| Ad title | ✅ |
| Ad text | ✅ (تبلیغ جستجو متن ندارد) |
| **URL you want to promote** | ✅ |
| **Ad photo or video** | ✅ اگر سفارش پوستر داشته باشد |
| Target specific channels | ✅ |
| کلیدواژه‌های جستجو | ✅ |
| CPM in Gram | ✅ فقط اگر خودتان عدد بدهید |
| Daily views limit | ✅ فقط اگر بخواهید |
| Initial status | ✅ روی **On Hold** می‌گذارد |
| **Initial budget in Gram** | ⛔ دست نمی‌زند |
| **تیک قوانین** | ⛔ نمی‌زند |
| **دکمهٔ Create Ad** | ⛔ نمی‌زند |

دربارهٔ Create Ad فقط به «نزدنش» بسنده نکرده‌ایم: تا وقتی این کد مشغول پر کردن
است، هر کلیکی روی آن دکمه — حتی اشتباهی — بی‌اثر می‌شود. وقتی کار تمام شد و
نوبت شما رسید، این محافظ برداشته می‌شود.

---

## نصب (یک‌بار)

دو فایل قابل دابل‌کلیک کنار همین فایل هست:

| فایل | کِی |
|---|---|
| **`1-ورود.bat`** | یک‌بار اول، و هر چند هفته که نشست منقضی شد |
| **`3-دستیار.bat`** | هر روز که می‌خواهید از دکمهٔ CRM استفاده کنید |

اولین بار که هرکدام را باز کنید، خودش `npm install` و نصب مرورگر را انجام
می‌دهد — چند دقیقه طول می‌کشد.

اگر برای باز شدن پنل به پروکسی محلی نیاز دارید، فایلی به اسم `proxy.txt`
کنار همین‌ها بسازید و فقط آدرسش را داخلش بنویسید، مثلاً:
`http://127.0.0.1:10809`

## ورود به حساب (یک‌بار، و هر چند هفته یک‌بار)

`1-ورود.bat` را دابل‌کلیک کنید. مرورگر باز می‌شود، خودتان با شمارهٔ خودتان
وارد `ads.telegram.org` می‌شوید (کد تأیید در تلگرام می‌آید)، بعد در پنجرهٔ
سیاه Enter می‌زنید. نشست در `session.json` ذخیره می‌شود و دفعات بعد لازم
نیست دوباره وارد شوید.

`session.json` کلید ورود به حساب تبلیغاتی شماست — نه در گیت می‌رود، نه جایی
کپی‌اش کنید.

## روش پیشنهادی: دستیار + دکمهٔ CRM

1. `3-دستیار.bat` را دابل‌کلیک کنید و باز نگه دارید. (فقط روی همین
   کامپیوتر گوش می‌دهد؛ کس دیگری بهش دسترسی ندارد.)
2. در پنل CRM (‎`/admin`) سفارش را باز کنید و **«پر کن (خودکار)»** را بزنید.
3. یک تب کروم باز می‌شود، وارد حساب تبلیغاتی‌تان می‌شود، و فرم را پر می‌کند —
   شامل URL و عکس. همان‌جا می‌ماند.
4. خودتان: بودجه (و CPM اگر پر نشده) را می‌گذارید، یک‌بار همه‌چیز را چک
   می‌کنید، تیک قوانین را می‌زنید و **Create Ad** را می‌زنید.

اگر دستیار باز نباشد، دکمه به‌جای خطای گنگ مرورگر، همین را می‌گوید: «اول
۳-دستیار را اجرا کنید».

هر سفارش یک تب تازه در همان مرورگر باز می‌کند؛ نیازی نیست هر بار از نو باز
شود. تا وقتی پنجرهٔ دستیار بسته نشده، دکمهٔ CRM برای هر سفارش دیگری هم کار
می‌کند.

## روش دوم: خط فرمان (اگر دستیار در دسترس نبود)

```bash
node fill.mjs order.json                       # CPM را خودم در پنل می‌نویسم
node fill.mjs order.json --cpm 0.12             # CPM را هم پر کن
node fill.mjs order.json --poster poster.jpg    # عکس را هم آپلود کن
```

مرورگر باز می‌ماند تا خودتان بودجه را بگذارید، همه‌چیز را چک کنید و
Create Ad را بزنید. عکس فرم پرشده در `out/` ذخیره می‌شود.

از پنل CRM (`/admin`) → صفحهٔ هر سفارش → دکمهٔ **«کپی برای تلگرام ادز»**.
متن کپی‌شده را در یک فایل `order.json` بریزید:

```json
{
  "id": "LK-1042",
  "type": "channel",
  "adTitle": "کمپین فروش پاییز",
  "text": "فروش ویژه لوازم جانبی موبایل با ۳۰٪ تخفیف",
  "hasPoster": false,
  "channels": ["@channel_one", "@channel_two"],
  "keywords": [],
  "url": "@lika_shop",
  "cpmGram": null,
  "dailyViewsLimit": null
}
```

- `type` یکی از `channel` / `bot` / `search`
- `cpmGram` واحدش **Gram** است، نه دلار. تبدیل ارز عمداً خودکار نیست —
  نرخ را خودتان می‌دانید، اسکریپت حق ندارد حدس بزند.
- عکس پوستر را باید خودتان جدا دانلود کنید (از CRM) و با ‎`--poster` بدهید؛
  در فایل order.json خودش ذخیره نمی‌شود.

## نصب دستی (اگر ترمینال را ترجیح می‌دهید)

روی همان کامپیوتری که می‌خواهید کار کند:

```bash
cd tools/tgads
npm install
npx playwright install chromium
npm run login     # یک‌بار
npm run agent     # همیشه، به‌جای دابل‌کلیک 3-دستیار.bat
```

> پنل تبلیغات تلگرام از داخل ایران باز نمی‌شود. یا اتصال کل سیستم باید بیرون
> باشد، یا آدرس پروکسی را بدهید:
> `TGADS_PROXY="http://127.0.0.1:10809" node agent.mjs`

## بار اول حتماً نگاه کنید

HTML پنل تلگرام مال ما نیست و ممکن است تغییر کند. کد هر فیلد را دو راه
مختلف پیدا می‌کند و اگر پیدا نکرد، به‌جای نوشتن در جای اشتباه، می‌گوید
«این را خودتان پر کنید». ولی بار اول با چشم خودتان چک کنید — مخصوصاً فهرست
کانال‌های هدف، URL و عکس را، چون بعد از ساخته‌شدن تبلیغ دیگر قابل تغییر نیست.

## یک نکتهٔ صادقانه

خودکارسازی پنل با شبیه‌سازی مرورگر معمولاً خلاف شرایط استفادهٔ این‌جور
پلتفرم‌هاست و بدترین حالتش تعلیق حساب تبلیغاتی است. اینکه بودجه و دکمهٔ نهایی
را خودتان می‌زنید، رفتار این ابزار را به یک «پرکنندهٔ فرم» نزدیک می‌کند نه
رباتی که خودش کمپین می‌سازد و پول خرج می‌کند — ولی ریسک صفر نیست. اگر روزی
حسابتان دسترسی API رسمی گرفت، آن راه هم امن‌تر است و هم پایدارتر.

دستیار (`agent.mjs`) فقط روی `127.0.0.1` گوش می‌دهد — از بیرون این کامپیوتر
اصلاً قابل دسترس نیست. ولی چون از داخل همان مرورگر صدا زده می‌شود، به‌طور فنی
هر صفحهٔ دیگری هم که همان لحظه در همان مرورگر باز باشد می‌تواند بهش درخواست
بفرستد. چون این ابزار هرگز بودجه یا دکمهٔ نهایی را لمس نمی‌کند، بدترین
حالتش باز شدن یک تب نیمه‌پرشده است، نه خرج پول — ولی همچنان بهتر است پنجرهٔ
دستیار را فقط وقتی لازم دارید باز نگه دارید، نه همیشه.
